# 追加设定

## 冥寂

大多数人类生活在一个虚假的世界中。 \
多斯科沃的公民们听说过幽灵、恶魔和超凡力量的传闻。他们将这些东西视为迷信——古老时代遗留下来的迷信，愚昧之人用来解释未知的廉价故事。他们相信，那些关于灵魂附身、关于异界存在、关于超凡力量的传说，不过是酒馆里的胡言乱语。

他们是错误的。

他们之所以能够保持这种“理智”，不是因为他们正确，而是一层厚重的帷幕蒙蔽了他们的感知。使徒们将这种集体性的认知障碍称为**冥寂**。 \
当一个人类目睹了无法用常理解释的超凡现象——一道凭空燃起的火焰，一个从尸体中升腾的灵魂，一个使徒身上浮现的异样印记——他的心灵会自动启动一套程序。 \
首先，他会试图合理化。那道火焰一定是炼金术士的戏法。那个幻影一定是煤气泄漏造成的幻觉。那些诡异的印记一定是某种罕见的皮肤病。只要能将他拉回熟悉的世界框架之内，任何解释都会被接纳。 \
如果合理化失败，遗忘就会接管。记忆变得模糊，细节开始脱落。几小时或几天后，那段经历会彻底消失，只留下一种无法归因的不安感。

但冥寂也不是绝对的。羔羊们的梦境有时会染上诡异的色彩，艺术家会在癫狂中画出从未见过的景象，孩童会在深夜惊醒。但这些碎片化的知觉，很快就会被日常生活抹平。 \
是谁维持着这层帷幕？ \
使徒们将答案指向**深渊**。

## 深渊

想象现实是一张编织精美的挂毯。人类看见的，是挂毯正面的图案——那些他们能够理解、能够命名、能够归类的事物：石头与钢铁，血肉与骨骼，生与死。完整、连贯、符合逻辑。 \
但使徒们知道，挂毯的背面是一团混乱的线头。那些被拒绝的真实并不会消失。它们坠落到挂毯的背面，穿过冥寂的帷幕，穿过现实的底层，最终沉入深渊。

在那里，它们堆积、聚合、发酵，喂养深渊中的存在，让深渊本身对现实产生越来越强的引力。 \
当深渊中的压力积累到一定程度，当被否定的真实太过庞大而无法被容纳，现实与深渊之间的边界就会被撕裂。 \
**裂隙**随之产生。

## 觉醒

大多数使徒曾经也是羔羊。 \
每一个使徒都经历过**觉醒**——冥寂的帷幕被撕裂的时刻。 \
觉醒不是恩赐，不是启蒙，不是升华。它是一次创伤。当一个人遭遇的超凡现象太过庞大、太过尖锐、太过不可否认，以至于他的心灵无法将其合理化或遗忘时，冥寂就会在她的认知上撕开一道伤口。
这道伤口永不愈合。 \
它成为使徒与深渊之间的连接通道。通过这道伤口，深渊中的东西可以渗入使徒；同时，使徒内心深处的某些东西，也会坠入深渊。

觉醒有多种形式。 \
有些人是在目睹至亲死亡后，看见死者的灵魂站在尸体旁。有些人是在极端危险中，听见来自内心深处的“另一种声音”。有些人是在触碰古老遗物时，感受到不属于自己的记忆在血管中奔涌。有些人是在长达数周的时间里，反复梦见同一个诡异的符号，直到那个符号在某一天“活过来”。 \
无论形式如何，它们都有一个共同点：**冥寂失效了**。

使徒看见了羔羊们看不见的东西。她看见街道上行走的“人”中，有些只是披着人皮的妖魔。她看见某些建筑的地基之下，埋藏着蠕动的东西。她看见天空之上，有什么东西正在凝视。 \
觉醒之后，新生的使徒会经历一段“余烬期”。冥寂的碎片仍然附着在她身上，试图修补那道裂缝。她会怀疑自己的理智，质疑自己的记忆，想要爬回温暖的谎言中去。 \
有些人确实爬回去了。她们成功地让自己相信那一切都是精神异常的产物。她们重新沉入冥寂，成为普通的羔羊。 \
而那些没有爬回去的人——那些选择凝视伤口的人——成为了真正的使徒。
